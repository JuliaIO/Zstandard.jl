Public API ​

Zstandard.compress Method
julia
compress(data; level=3, checksum=false) -> Vector{UInt8}

Compress data (a byte vector or string) into a Zstandard frame.

level ranges from -7 (fastest) to 22 (strongest); 0 selects the default level 3, as in libzstd. With checksum=true an XXH64 content checksum is appended. Inputs larger than 1 GiB are written as several concatenated frames.

source
Zstandard.decompress Function
julia
decompress(data::AbstractVector{UInt8}, dict::Union{Nothing, ZstdDictionary}=nothing)

Decompress Zstandard compressed data, which may contain several concatenated and/or skippable frames. Optionally, a ZstdDictionary can be provided. Throws a ZstdError if the data is malformed.

source

Streaming ​

Zstandard.Streaming.ZstdDecompressorStream Type
julia
ZstdDecompressorStream(io::IO, dict::Union{Nothing, ZstdDictionary}=nothing)

A streaming Zstandard decompressor that implements the IO interface. Decoded data is produced one block at a time; memory use is bounded by the frame's window size plus one block.

After a decoding error (a ZstdError), the stream is unusable: later reads rethrow the same error (bytes decoded before it can still be read). Other exceptions, such as an interrupt or an error from io, are not sticky.

source

Decode one compressed block at src[1:len] and write its output at op. hist is the earliest valid match source within the output buffer (frame start); olimit bounds the output. Returns the new output pointer.

Zstandard.Decoder.parse_dictionary Method
julia
parse_dictionary(data::AbstractVector{UInt8}) -> ZstdDictionary

Parse a Zstandard dictionary. Data starting with the dictionary magic number 0xEC30A437 is parsed as a formatted dictionary (ID, entropy tables, repeat offsets, content); anything else is treated as raw content with ID 0.
