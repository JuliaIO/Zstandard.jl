Zstandard.ZstdFrameHeader Type
julia
ZstdFrameHeader

Information from a Zstandard frame header, as returned by frame_header.

  • content_size: decompressed size, or nothing if the header does not record it

  • window_size: window size required to decode the frame

  • dict_id: dictionary ID, 0 if none

  • checksum: whether the frame ends with an XXH64 content checksum

  • single_segment: whether the frame is a single segment (window = content size)

  • header_size: size of the frame header in bytes, including the magic number

Zstandard.compress Method
julia
compress(data; level=3, checksum=false, dict=nothing, nthreads=1, long=false) -> Vector{UInt8}

Compress data (a byte vector or string) into a Zstandard frame.

level ranges from -7 (fastest) to 22 (strongest); 0 selects the default level 3, as in libzstd. With checksum=true an XXH64 content checksum is appended. With a ZstdDictionary, its content serves as history and, for formatted dictionaries, its entropy tables and repeat offsets are used; the frame records the dictionary ID. Inputs larger than 1 GiB are written as several concatenated frames.

With nthreads > 1, inputs larger than a few window sizes are split into jobs compressed in parallel tasks (within a single frame, as libzstd's nbWorkers); start Julia with several threads (julia -t N) to benefit. The output differs slightly from single-threaded compression. Not combined with dict or long (those always run on one thread).

With long=true, long-distance matching finds repetitions up to 128 MiB apart (as zstd --long); the frame then declares a window of up to 128 MiB, which decoders must be willing to allocate.

Zstandard.Streaming.StreamDecoder Type
julia
StreamDecoder(dict=nothing)

Incremental Zstandard decoder. Feed input with feed! (at most needed bytes are consumed per call); decoded bytes are available in d.out[d.rpos:d.wpos].

source
Zstandard.Streaming.ZstdCompressorStream Type
julia
ZstdCompressorStream(io::IO; level=3, checksum=false, dict=nothing, close_io=true)

A streaming Zstandard compressor implementing the writable IO interface. Data written to the stream is compressed into a single frame (without a content size) and written to io block by block. flush emits all pending data as a complete block, so everything written so far can be decoded. close finishes the frame and, if close_io is true, closes io (pass close_io=false to keep writing to io, e.g. an IOBuffer read afterwards).

source
Zstandard.Streaming.ZstdDecompressorStream Type
julia
ZstdDecompressorStream(io::IO, dict::Union{Nothing, ZstdDictionary}=nothing)

A streaming Zstandard decompressor that implements the IO interface. Decoded data is produced one block at a time; memory use is bounded by the frame's window size plus one block.

After a decoding error (a ZstdError), the stream is unusable: later reads rethrow the same error (bytes decoded before it can still be read). Other exceptions, such as an interrupt or an error from io, are not sticky.

Zstandard.Encoder.train_dictionary Method
julia
train_dictionary(samples; dict_size=112640, level=3, k=nothing, d=8, f=20) -> Vector{UInt8}

Train a formatted Zstandard dictionary from samples (a vector of byte vectors) with the fastCover algorithm and entropy finalization, as zstd --train. When k (segment size) is not given, several values are tried and scored by compressing a held-out quarter of the samples. dmers of d bytes are hashed into 2^f buckets (f in 1:31). Use the result with parse_dictionary.
